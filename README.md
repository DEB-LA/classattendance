# Class Attendance Tracker

A clean, responsive, and lightweight class attendance list web app built with vanilla HTML, CSS, and JavaScript.

## Features

- **Add Attendance Records**: Enter student name, select date, and mark status as Present or Absent.
- **Local Persistence**: Saves all records directly in browser `localStorage` — data stays after page refresh.
- **Top Counters**: Real-time summary showing total attendance records, present count, and absent count.
- **Search & Filters**: Search live by student name or date, with quick filters for All, Present, or Absent.
- **Edit & Delete**: Edit any record inline, and delete records with a confirmation dialog.
- **Empty State**: Friendly messaging when no records are found or saved.
- **Mobile Friendly**: Fully responsive design with touch-friendly controls.

## Getting Started

No build tools, servers, or databases needed! Simply open `index.html` in any web browser.
